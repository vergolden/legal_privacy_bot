# Legal Privacy — контент-бот

Telegram-бот и набор скриптов для автоматизации соцсетей компании **Legal Privacy**: поиск новостей по 152-ФЗ/защите персональных данных, подготовка поста (текст + картинка), доставка на утверждение и публикация в ВКонтакте и Telegram-канал по нажатию кнопки.

Подробный бриф проекта (проблема, пользователь, минимальный функционал) — в [`PROJECT_BRIEF.md`](PROJECT_BRIEF.md).

## Как это устроено

```
Команда запускает поиск (/digest)
      │
      ▼
Claude Code skill news-152fz ── поиск + оформление дайджеста новостей
      │
      ▼
Claude Code skill news-to-social ── текст поста + промпт для картинки
      │
      ▼
generate_image.py ── картинка (ProxyAPI, GPT Image)
      │
      ▼
bot_listener.py ── черновик с кнопками в личные чаты (Андрей + жена)
      │
      │  кнопка «Опубликовать»
      ▼
publish_vk.py + publish_telegram.py ── пост одновременно в ВК-сообщество и Telegram-канал
```

Кнопки в боте также позволяют отредактировать текст, убрать/добавить картинку, отправить в архив или отклонить черновик — без выхода из Telegram.

## Важно: зависимость от родительской папки

Этот репозиторий — только код бота (`scripts/`). Исторически он живёт как подпапка внутри рабочей директории проекта Legal Privacy и по умолчанию ожидает рядом, **на уровень выше себя**:

- `.env` — переменные окружения (см. [`.env.example`](.env.example))
- `social_posts/` — черновики и архив постов (`YYYY/month/пост_DD-MM-YYYY.json`)
- `news_digests/` — дайджесты новостей от скилла `news-152fz`

Без этой структуры рядом скрипты не запустятся. Путь к `.env` можно переопределить флагом `--env-file` у скриптов, где он реализован (`publish_telegram.py`, `generate_image.py`, `send_telegram.py`).

## Файлы

| Файл | Назначение |
|---|---|
| `bot_listener.py` | Telegram-бот, long polling: приём команды `/digest`, обработка кнопок (публикация/редактирование/архив/отказ) |
| `telegram_api.py` | Общий клиент Telegram Bot API (запросы, обработка ошибок) |
| `post_buttons.py` | Разметка инлайн-кнопок и путей к файлам постов |
| `publish_vk.py` | Публикация поста в сообщество ВК (Community/User Token) |
| `publish_telegram.py` | Публикация поста в Telegram-канал |
| `send_telegram.py` | Доставка черновика (текст + кнопки) в личные чаты на утверждение |
| `generate_image.py` | Генерация картинки к посту через ProxyAPI (GPT Image) |

## Запуск

```bash
cp .env.example ../.env    # заполнить реальными значениями
python3 bot_listener.py    # long polling, работает пока запущен процесс
```

## Технологии

Python 3, только стандартная библиотека (сознательное решение — без сторонних зависимостей). Telegram Bot API, VK API, ProxyAPI.ru. Обход блокировки `api.telegram.org` из РФ-дата-центров — через прокси-релей на Cloudflare Workers (настраивается на стороне вызывающих скриптов сайта, не в этом репозитории).
