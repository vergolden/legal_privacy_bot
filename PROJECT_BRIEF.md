# Project Brief: Контент-пайплайн Legal Privacy (Telegram-бот)

## Название
**Legal Privacy Content Bot** — автоматизированный пайплайн поиска новостей, подготовки и публикации постов о 152-ФЗ/защите персональных данных в соцсети

## Проблема
Экспертная компания обязана регулярно вести соцсети (ВК, Telegram-канал), чтобы подтверждать экспертизу и приводить клиентов. Но ежедневный поиск релевантных новостей по 152-ФЗ, ПДн и информационной безопасности, их анализ и упаковка в готовый пост с картинкой — рутинная, времязатратная работа. В команде из двух человек (операционный директор + юрист) этим некому заниматься каждый день без отрыва от основной работы с клиентами.

## Пользователь
Внутренний инструмент команды Legal Privacy — Андрей (запускает пайплайн, публикует) и его супруга (финальное юридическое согласование контента перед публикацией). Не предназначен для конечных клиентов компании.

## Основная функция
- **Вход:** команда запускает поиск (командой `/digest` в Telegram-боте)
- Скилл `news-152fz` ищет новости по теме дня через веб-поиск, оформляет дайджест
- Скилл `news-to-social` превращает дайджест в текст поста, генерирует промпт и саму картинку (через ProxyAPI, модели семейства GPT Image)
- Бот (`bot_listener.py`, long polling Telegram) присылает черновик поста с картинкой и кнопками в личные чаты обоих участников команды
- По кнопкам: **Опубликовать** (в ВК-сообщество и Telegram-канал одновременно), **Редактировать текст**, **Убрать/добавить картинку**, **В архив**, **Отклонить**
- **Выход:** опубликованный пост в двух соцсетях одновременно + запись события в журнал публикаций

## Формат результата
Согласованный обеими сторонами пост, опубликованный в `vk.com/legalprivacy` и Telegram-канале `@legal_privacy152DPO`, с логом в `social_posts/` (кто одобрил, когда опубликовано).

## Минимальный функционал
Реализовано и работает в бою:
- Поиск и оформление ежедневного дайджеста новостей
- Автогенерация текста поста и изображения из дайджеста
- Доставка черновика на утверждение в личные чаты с интерактивными кнопками
- Публикация по кнопке одновременно в ВК и Telegram-канал
- Редактирование текста и управление картинкой прямо в диалоге с ботом
- Архивирование и отклонение черновиков

Планируется:
- Автозапуск по расписанию без ручного триггера `/digest`
- Перенос бота с ноутбука на постоянный хостинг (VPS) — сейчас работает, только пока процесс запущен локально

## Технологии
- **Язык:** Python 3, сознательно только стандартная библиотека (без сторонних зависимостей)
- **Telegram Bot API** — long polling, доставка черновиков и кнопки управления
- **VK API** — публикация в сообщество (Community Token + User Token)
- **ProxyAPI.ru** — генерация изображений (прокси к моделям семейства GPT Image)
- **Cloudflare Workers** — прокси-релей для обхода блокировки `api.telegram.org` из РФ-дата-центров
- **Claude Code skills** (`news-152fz`, `news-to-social`) — ядро генерации контента, оркестрируются скиллом `legal-privacy-daily-pipeline`
